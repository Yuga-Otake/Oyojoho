# 応用情報 学習アプリ

応用情報技術者試験(AP)の午前問題対策を行う、ブラウザだけで動く学習アプリです。
ビルドもサーバも不要で、`index.html` を開けばそのまま動作します。

**公開URL: https://yuga-otake.github.io/Oyojoho/**

## 特長

- **110問の四択問題バンク** — テクノロジ系69問 / マネジメント系18問 / ストラテジ系23問。全問に解説付き
- **計算フロー(12問・48ステップ)** — 計算問題を「迷いどころ」ごとのステップに分解し、1ステップずつ選択肢を選んで解き進める。誤答すると、なぜその選び方だと間違うのかをその場で指摘し、正解するまで同じステップにとどまる
- **3つの出題モード**
  - 演習 … 1問ごとに正誤と解説を確認しながら進める
  - 模擬試験 … 解説を伏せて出題し、制限時間つきで最後にまとめて採点
  - 復習 … 間隔反復で期限が来た問題だけを出題
- **間隔反復(SRS)** — SM-2 を簡略化したアルゴリズム。正解すると次回までの間隔が伸び、誤答するとリセットされて当日の復習キューに戻る
- **苦手優先の出題** — 正答率の低い順、未出題優先、復習期限順などの並べ替えに対応
- **学習統計** — 通算正答率、網羅率、連続学習日数、分野別正答率、直近12週の学習カレンダー、苦手問題ワースト10
- **用語・公式集** — 稼働率、EVM、損益分岐点など頻出の計算式と用語をキーワード検索できるチートシート
- **オフライン / プライバシ** — 学習履歴はブラウザの localStorage にのみ保存。サーバへは一切送信しない。JSON でのエクスポート / インポートに対応
- **ダークモード対応・スマートフォン対応**

## 使い方

`index.html` をブラウザで開くだけです。

```bash
git clone https://github.com/Yuga-Otake/Oyojoho.git
cd Oyojoho
open index.html          # macOS (Windows は start、Linux は xdg-open)
```

ローカルサーバ経由で開きたい場合:

```bash
npx http-server . -p 8080    # → http://localhost:8080
```

### GitHub Pages への公開

`.github/workflows/pages.yml` により、このブランチへ push するたびに GitHub Pages へ自動デプロイされます。

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を
**「GitHub Actions」** に設定してください(ワークフローからこの設定自体を変更することはできないため)。
設定後、push するか Actions タブから `Deploy to GitHub Pages` を再実行すると公開されます。

ブランチから直接配信したい場合は、Source を「Deploy from a branch」にして対象ブランチの `/ (root)` を指定します。
その場合 `.github/workflows/pages.yml` は不要です。

### キーボード操作

| キー | 動作 |
| --- | --- |
| `1` 〜 `4` | 選択肢(ア〜エ)を選ぶ |
| `Enter` / `Space` | 次の問題へ / 採点する |
| `←` | 前の問題へ(模擬試験モードのみ) |

計算フロー画面でも `1`〜`4` と `Enter` が同じように使えます。

## ディレクトリ構成

```
.
├── index.html                      画面のマークアップ
├── css/
│   └── style.css                   スタイル(テーマ変数・レスポンシブ)
└── js/
    ├── data/
    │   ├── questions-technology.js テクノロジ系の問題
    │   ├── questions-management.js マネジメント系の問題
    │   ├── questions-strategy.js   ストラテジ系の問題
    │   ├── flows.js                計算フロー問題
    │   └── glossary.js             用語・公式集
    ├── storage.js                  localStorage への永続化
    ├── srs.js                      間隔反復アルゴリズム
    ├── stats.js                    学習履歴の集計
    ├── quiz.js                     出題プールの作成とセッション管理
    ├── flow.js                     計算フローの進行と判定
    └── app.js                      画面制御とイベント処理
```

ビルドツールや外部ライブラリには依存していません。`js/` 以下はクラシックスクリプトとして読み込み、`window` 上の名前空間 (`AppStorage`, `SRS`, `Stats`, `Quiz`, `FlowMode`) を介して連携します。

## 問題を追加する

`js/data/questions-*.js` の配列に、次の形式のオブジェクトを追加するだけです。

```js
{
  id: 'TC070',                   // 一意なID(TC=テクノロジ, MG=マネジメント, ST=ストラテジ)
  category: 'テクノロジ系',       // 大分類
  field: 'ネットワーク',          // 分野(絞込みと統計の単位)
  topic: 'プロトコル',            // 小分類(任意)
  difficulty: 2,                 // 1=基本, 2=標準, 3=応用
  question: '問題文',
  choices: ['選択肢1', '選択肢2', '選択肢3', '選択肢4'],
  answer: 0,                     // choices の 0 始まりインデックス
  explanation: '解説文'
}
```

追加した `field` は演習画面の絞込みチップと統計に自動的に反映されます。

解説文では **選択肢を「2番目」「選択肢3」のように位置で参照しない** でください。
既定では出題時に選択肢の順序をシャッフルするため、位置参照は表示とずれます。
誤答選択肢に言及するときは「保険による移転はリスク移転」のように内容で書きます。

## 計算フローを追加する

`js/data/flows.js` の配列に、次の形式で追加します。1ステップが1つの「迷いどころ」に対応します。

```js
{
  id: 'FL013',
  category: 'テクノロジ系',
  field: 'ネットワーク',
  topic: 'データ転送時間',
  difficulty: 2,
  title: '一覧に表示する短いタイトル',
  scenario: '問題文(全ステップを通して画面上部に表示される)',
  steps: [
    {
      pitfall: '単位をそろえる',          // 迷いどころの見出し
      prompt: 'このステップで問うこと',
      choices: ['選択肢1', '選択肢2', '選択肢3', '選択肢4'],
      answer: 1,                          // 0 始まりインデックス
      explanation: '正解したときに示す解説',
      traps: {                            // 誤答インデックス -> なぜ誤りか
        0: 'この選び方だとこうなります…',
        2: '…',
        3: '…'
      }
    }
  ],
  summary: '完了画面に出す要点のまとめ'
}
```

`traps` は正解以外の3つすべてに書いてください。**「なぜその選択肢を選んでしまうのか」という誤りの筋道**を書くのが、このモードの要点です。単に「誤りです」ではなく「8で割ってしまっています。バイト→ビットは8倍です」のように、どこで道を間違えたかを指摘します。

選択肢の表示順は設定の「選択肢の順序をシャッフル」に連動し、`traps` の対応も自動で付け替わります。

## 学習データについて

- 保存先: `localStorage` のキー `ap-study-app:v1`
- 保存内容: 問題ごとの正誤回数と復習スケジュール、計算フローの成績、日別の学習量、連続学習日数、直近100件のセッション結果、表示設定
- ブラウザのデータを消去すると学習履歴も失われます。設定画面からエクスポートしておけば、別の端末やブラウザにインポートして引き継げます

## 収録問題について

収録している問題は、IPA が公開する応用情報技術者試験のシラバスの出題範囲に沿って作成したオリジナル問題です。実際の過去問題そのものではありません。試験制度や出題範囲の最新情報は IPA の公式サイトを参照してください。
