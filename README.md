# 応用情報・支援士 学習アプリ

応用情報技術者試験(AP)と情報処理安全確保支援士試験(SC)の対策を行う、ブラウザだけで動く学習アプリです。
画面上部の「応用情報 / 支援士」で対象の試験を切り替えます(`index.html?exam=sc` のように URL でも指定できます)。
ビルドもサーバも不要で、`index.html` を開けばそのまま動作します。

**公開URL: https://yuga-otake.github.io/Oyojoho/**

## 特長

### 情報処理安全確保支援士(SC)モード

- **午前II形式の四択 71問** — 暗号・認証・PKI/TLS・Web・ネットワーク攻撃・マルウェア・対策技術・メール・無線/IoT・マネジメント・法規と関連分野(ネットワーク・DB・開発・監査)。模擬試験は本番と同じ25問・40分
- **午後演習(記述式)5事例** — 図表付きの事例を読んで設問に答える。記述式は解答を確定すると解答例と「採点の観点」が表示され、観点のキーワードが含まれているかを自動照合したうえで ○/△/× を自己採点する。字数制限のカウンタ付き
- **支援士の教科書(15章・30節)と体感ビジュアル 13種を追加** — ECB と CBC の模様の違い、DH 鍵共有と中間者、パスワードの総当たり時間、OAuth 認可コードフロー、TLS 1.3 ハンドシェイクと中間者攻撃、XSS の多層防御、CSRF、キャッシュポイズニングの成功確率、リフレクション攻撃、ファイアウォールのルール並べ替え、IPsec のパケット構造、SPF/DKIM/DMARC の判定シミュレータ、ALE と費用対効果
- 間違いノート・間隔反復・統計・用語集は試験ごとに切り替わる(学習データは1つにまとめて保存)

### 共通

- **110問の四択問題バンク** — テクノロジ系69問 / マネジメント系18問 / ストラテジ系23問。全問に解説付き
- **計算フロー(12問・48ステップ)** — 計算問題を「迷いどころ」ごとのステップに分解し、1ステップずつ選択肢を選んで解き進める。誤答すると、なぜその選び方だと間違うのかをその場で指摘し、正解するまで同じステップにとどまる
- **教科書(20章・78節)** — 全110問・全計算フローの出題範囲を、分野ごとに「要点・本文・公式・押さえどころ・ひっかけ注意・例題」で解説。問題は `field` / `topic` で節に自動で対応づけられる
- **体感ビジュアル(37種)** — スライダやボタンで動かして仕組みを確かめる図解。2の補数のビット操作、待ち行列の「爆発」、1000個で数えるベイズ、整列アルゴリズムの比較回数、RAID の故障シミュレーション、FIFO/LRU のページ置換え、デッドロック、障害回復の判断、サブネット、鍵の選び方、SHA-256 の雪崩効果、SQL インジェクション、クリティカルパス、EVM、損益分岐点グラフなど。「体感ラボ」から単体でも開ける
- **間違いノート** — 誤答した問題を単元ごとに集約し、自分が選んだ誤答・正解・解説を並べて表示。「① 解説を読む → ② 体感ビジュアルで確かめる → ③ 解き直す」の3ステップの達成状況を記録し、2回連続で正解すると「克服」になる
- **どこからでも教科書へ** — 演習中の解説欄、結果画面の振り返り、苦手問題一覧、計算フローの完了画面から「📖 教科書で復習する」で該当する節を開ける(出題中はモーダルで表示)
- **3つの出題モード**
  - 演習 … 1問ごとに正誤と解説を確認しながら進める
  - 模擬試験 … 解説を伏せて出題し、制限時間つきで最後にまとめて採点
  - 復習 … 間隔反復で期限が来た問題だけを出題
- **間隔反復(SRS)** — SM-2 を簡略化したアルゴリズム。正解すると次回までの間隔が伸び、誤答するとリセットされて当日の復習キューに戻る
- **苦手優先の出題** — 正答率の低い順、未出題優先、復習期限順などの並べ替えに対応
- **学習統計** — 通算正答率、網羅率、連続学習日数、分野別正答率、直近12週の学習カレンダー、苦手問題ワースト10
- **用語・公式集** — 稼働率、EVM、損益分岐点など頻出の計算式と用語をキーワード検索できるチートシート
- **オフライン / プライバシ** — 学習履歴はブラウザの localStorage にのみ保存。サーバへは一切送信しない。JSON でのエクスポート / インポートに対応
- **ダークモード対応・スマートフォン対応**

## 使い方

`index.html` をブラウザで開くだけです。

```bash
git clone https://github.com/Yuga-Otake/Oyojoho.git
cd Oyojoho
open index.html          # macOS (Windows は start、Linux は xdg-open)
```

ローカルサーバ経由で開きたい場合:

```bash
npx http-server . -p 8080    # → http://localhost:8080
```

### GitHub Pages への公開

`.github/workflows/pages.yml` により、このブランチへ push するたびに GitHub Pages へ自動デプロイされます。

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を
**「GitHub Actions」** に設定してください(ワークフローからこの設定自体を変更することはできないため)。
設定後、push するか Actions タブから `Deploy to GitHub Pages` を再実行すると公開されます。

ブランチから直接配信したい場合は、Source を「Deploy from a branch」にして対象ブランチの `/ (root)` を指定します。
その場合 `.github/workflows/pages.yml` は不要です。

### キーボード操作

| キー | 動作 |
| --- | --- |
| `1` 〜 `4` | 選択肢(ア〜エ)を選ぶ |
| `Enter` / `Space` | 次の問題へ / 採点する |
| `←` | 前の問題へ(模擬試験モードのみ) |

計算フロー画面でも `1`〜`4` と `Enter` が同じように使えます。

## 問題を追加する

`js/data/questions-*.js` の配列に、次の形式のオブジェクトを追加するだけです。

```js
{
  id: 'TC070',                   // 一意なID(TC=テクノロジ, MG=マネジメント, ST=ストラテジ)
  category: 'テクノロジ系',       // 大分類
  field: 'ネットワーク',          // 分野(絞込みと統計の単位)
  topic: 'プロトコル',            // 小分類(任意)
  difficulty: 2,                 // 1=基本, 2=標準, 3=応用
  question: '問題文',
  choices: ['選択肢1', '選択肢2', '選択肢3', '選択肢4'],
  answer: 0,                     // choices の 0 始まりインデックス
  explanation: '解説文'
}
```

追加した `field` は演習画面の絞込みチップと統計に自動的に反映されます。

解説文では **選択肢を「2番目」「選択肢3」のように位置で参照しない** でください。
既定では出題時に選択肢の順序をシャッフルするため、位置参照は表示とずれます。
誤答選択肢に言及するときは「保険による移転はリスク移転」のように内容で書きます。

## 計算フローを追加する

`js/data/flows.js` の配列に、次の形式で追加します。1ステップが1つの「迷いどころ」に対応します。

```js
{
  id: 'FL013',
  category: 'テクノロジ系',
  field: 'ネットワーク',
  topic: 'データ転送時間',
  difficulty: 2,
  title: '一覧に表示する短いタイトル',
  scenario: '問題文(全ステップを通して画面上部に表示される)',
  steps: [
    {
      pitfall: '単位をそろえる',          // 迷いどころの見出し
      prompt: 'このステップで問うこと',
      choices: ['選択肢1', '選択肢2', '選択肢3', '選択肢4'],
      answer: 1,                          // 0 始まりインデックス
      explanation: '正解したときに示す解説',
      traps: {                            // 誤答インデックス -> なぜ誤りか
        0: 'この選び方だとこうなります…',
        2: '…',
        3: '…'
      }
    }
  ],
  summary: '完了画面に出す要点のまとめ'
}
```

`traps` は正解以外の3つすべてに書いてください。**「なぜその選択肢を選んでしまうのか」という誤りの筋道**を書くのが、このモードの要点です。単に「誤りです」ではなく「8で割ってしまっています。バイト→ビットは8倍です」のように、どこで道を間違えたかを指摘します。

選択肢の表示順は設定の「選択肢の順序をシャッフル」に連動し、`traps` の対応も自動で付け替わります。

## 教科書の節を追加する

`js/data/textbook-*.js` の章(`field` ごと)の `sections` に追加します。

```js
{
  id: 'net-ip',                       // 一意なID
  title: 'IPアドレスとサブネット',
  topics: ['IPアドレス', 'サブネット'], // この節で扱う問題・フローの topic
  lead: '一言でいうと…',
  body: ['段落。**強調** と `コード` が使える'],
  table: { head: [...], rows: [[...]] },   // 任意
  formulas: [['名前', '式']],              // 任意
  points: ['押さえどころ'], traps: ['ひっかけ'],
  example: { q: '例題', steps: ['手順'], a: '答え' }, // 任意
  visual: 'subnet'                    // js/visuals/*.js で登録した体感ビジュアルのID(任意)
}
```

問題は「同じ `field` で `topics` に含まれる節」→「`topics` が一致する節」→「その分野の最初の節」の順に対応づけられます。
体感ビジュアルは `Visuals.register('id', { title, desc, mount(root) })` で登録します。

## 支援士の問題・午後事例を追加する

午前II の問題は `js/data/sc-questions.js`(ID は `SA` で始める)、教科書は `js/data/sc-textbook.js` に、AP と同じ形式で追加します。

午後事例は `js/data/sc-cases.js` に追加します。

```js
{
  id: 'SCP06', title: '事例のタイトル', field: 'Webセキュリティ', topic: 'XSS', difficulty: 2, minutes: 30,
  scenario: ['問題文の段落'],
  materials: [{ title: '図1 …', pre: 'ログや設定(等幅で表示)' }],
  questions: [
    { no: '設問1', type: 'choice', field: '…', topic: '…', prompt: '…', choices: ['…', '…', '…', '…'], answer: 0, explanation: '…' },
    { no: '設問2', type: 'text', field: '…', topic: '…', prompt: '…', limit: 40,
      model: '解答例', keywords: [['HttpOnly'], ['スクリプト', 'JavaScript']], explanation: '…' }
  ],
  summary: '事例のまとめ'
}
```

`keywords` は採点の観点で、内側の配列は同義語(どれか1つが含まれていれば観点を満たす)。解答例が `limit` 字以内に収まり、すべての観点を満たすようにしてください。

## 学習データについて

- 保存先: `localStorage` のキー `ap-study-app:v1`
- 保存内容: 問題ごとの正誤回数と復習スケジュール(誤答時に選んだ選択肢を含む)、教科書の節ごとの復習ステップ、計算フローの成績、日別の学習量、連続学習日数、直近100件のセッション結果、表示設定
- ブラウザのデータを消去すると学習履歴も失われます。設定画面からエクスポートしておけば、別の端末やブラウザにインポートして引き継げます

## 収録問題について

収録している問題は、IPA が公開する応用情報技術者試験のシラバスの出題範囲に沿って作成したオリジナル問題です。実際の過去問題そのものではありません。試験制度や出題範囲の最新情報は IPA の公式サイトを参照してください。
