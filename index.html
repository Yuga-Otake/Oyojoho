        🤖 AI 採点(Google Gemini)

        午後演習の記述式の解答を、Gemini API で採点・講評できます。API キーは Google AI Studio で発行してください。

        API キーはこの端末のブラウザにだけ保存され、学習データのエクスポートには含まれません。採点時には、事例の問題文・設問・解答例と、あなたの解答が Google に送信されます。 公開ページで使う場合は、Google Cloud コンソールでキーに「HTTP リファラー」の制限(このサイトの URL のみ許可)と、Generative Language API のみの API 制限を付けることをおすすめします。

        学習データ

        学習履歴はこのブラウザ内(localStorage)にのみ保存されます。機種変更時はエクスポートしてください。

        このアプリについて

        応用情報技術者試験(AP)と情報処理安全確保支援士試験(SC)の対策アプリです。の収録問題は 0 問。試験制度・出題範囲はIPAのシラバスを参照してください。

        問題はシラバスの出題範囲に沿って作成したオリジナル問題です。実際の過去問題そのものではありません。
